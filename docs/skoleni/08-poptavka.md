Doklady zatím nepřikládejte. Způsob bezpečného předání domluvíme následně. Do první poptávky nepatří seznam zaměstnanců, rodná čísla, skeny průkazů, zdravotní dokumentace ani diagnózy. Pokud některý údaj neznáte, napište to; samotné nevyplnění neurčuje výsledek posouzení.

Polarita následně upřesní požadovaný stupeň a rozsah, vstupní podklady, místo, cenu a termín. Podklady jednotlivých uchazečů se ověřují v dalším kroku. Vyplněné poptávky se neukládají do veřejného Git repozitáře.
